## 1. 枚举值模式（使用 enumCode）

### 示例1：基础枚举选择
```vue
<el-form-item label="订单类型" prop="purchaseOrderType">
  <fetch-select
    :request="fetchOptions"
    enumCode="PurchaseOrderTypeEnum"
    v-model="form.purchaseOrderTypeList"
    placeholder="请选择"
    clearable
    multiple
    filterable
  />
</el-form-item>

// 方法部分
async fetchOptions (code) {
  if (code) {
    return getEnum(code);
  }
  return [];
},
```

## 3. 带 change 事件的使用

### 示例1：备件选择触发添加表格数据
```vue
<fetch-select
  style="width: 300px;"
  :remote-method="queryListData"
  remote
  placeholder="请输入编码或名称"
  clearable
  value-key="id"
  label-key="partName"
  subLabelKey="partCode"
  @change="handleAddTableData"
  filterable
/>

// 方法部分
async queryListData (query) {
  try {
    const res = await listDealerPart({ dealerCode: this.form.dealerCode, partCodeOrNameLike: query });
    return res;
  } catch (error) {
    console.error('Error fetching series list:', error);
  }
},

handleAddTableData (val, record) {
  if (!record) {
    this.$message.warning('请先选择数据');
    return;
  }
  // 检查是否已存在...
},
```

## 4. 属性说明

| 属性 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `v-model` | String/Array | 绑定值 | `form.dealerCodeList` |
| `:request` | Function | 枚举请求方法（与enumCode配合使用） | `fetchOptions` |
| `enumCode` | String | 枚举码 | `"PurchaseOrderTypeEnum"` |
| `:remote-method` | Function | 远程搜索方法 | `getDealerList` |
| `remote` | Boolean | 是否开启远程搜索 | `true` |
| `filterable` | Boolean | 是否可搜索 | `true` |
| `clearable` | Boolean | 是否可清空 | `true` |
| `multiple` | Boolean | 是否多选 | `true` |
| `collapseTags` | Boolean | 多选时是否折叠显示 | `true` |
| `placeholder` | String | 占位提示文字 | `"请选择"` |
| `labelKey` | String | 选项标签字段名 | `"orgName"` |
| `valueKey` | String | 选项值字段名 | `"orgCode"` |
| `subLabelKey` | String | 副标签字段名（显示在右侧） | `"orgCode"` |
| `disabled` | Boolean | 是否禁用 | `true` |
| `@change` | Function | 选中值改变时触发 | `handleChange(val, record)` |

---

## 5. 常用接口导入

```javascript
import { getEnum, listOrgStoreInfoByParam, listWarehouse, listVehicleModel } from '@/api/common';
```

---

## 6. 注意事项

1. **多选模式下**，v-model 绑定的是数组类型，字段名通常以 `List` 结尾（如 `dealerCodeList`）
2. **单选模式下**，v-model 绑定的是字符串类型，字段名通常为单数（如 `submitter`）
3. **枚举模式**使用 `:request` + `enumCode` 组合
4. **远程搜索模式**使用 `:remote-method` + `remote` 组合
5. **change 事件**回调参数为 `(val, record)`，其中 `record` 是选中的完整数据对象
6. **字段映射**使用驼峰命名：`labelKey`、`valueKey`、`subLabelKey`

## 4. 属性说明

| 属性 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `v-model` | String/Number/Array | 绑定值 | `form.warehouseId` |
| `listUrl` | String | 列表请求接口地址 | `"/sp/web/basic/supplierInfo/list"` |
| `placeholder` | String | 占位提示文字 | `"请选择"` |
| `labelKey` | String | 选项标签字段名 | `"supplierName"` |
| `valueKey` | String | 选项值字段名 | `"id"` |
| `clearable` | Boolean | 是否可清空 | `true` |
| `filterable` | Boolean | 是否可搜索 | `true` |
| `multiple` | Boolean | 是否多选 | `true` |
| `disabled` | Boolean | 是否禁用 | `true` |
| `params` | Object | 请求参数 | `{seriesIdList: form.vehicleSeriesIds}` |
| `@change` | Function | 选中值改变时触发 | `handleChange(val)` |

---

## 5. 与 FetchSelect 的区别

| 特性 | ListSelect | FetchSelect |
|------|------------|-------------|
| 数据来源 | listUrl 接口地址 | request 方法或 remote-method |
| 枚举支持 | 不支持 | 支持（enumCode） |
| 远程搜索 | 内置分页查询 | remote-method 自定义 |
| 使用场景 | 列表数据选择 | 枚举/远程搜索/复杂场景 |
| 参数传递 | params 对象 | 方法内自定义 |

---

## 6. 注意事项

1. **多选模式下**，v-model 绑定的是数组类型，字段名通常以 `List` 或 `Ids` 结尾（如 `vehicleSeriesIdList`、`vehicleSeriesIds`）
2. **单选模式下**，v-model 绑定的是字符串或数字类型
3. **联动查询**通过 `:params` 传递关联字段值实现
4. **listUrl** 是完整的接口路径，会自动处理分页
5. **字段映射**使用驼峰命名：`labelKey`、`valueKey`
6. 组件路径为 `@/libs/components/list-select/index.vue` 或简写 `@/libs/components/list-select`
